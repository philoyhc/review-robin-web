# Browser check files

Upload files and a run order for the sections of
`guide/things_to_check_in_browser.md` that need one, one folder per set
of sections. Delete a folder in the same change that deletes the last
section pointing to it.

Lasting mock data for a demo or a manual run lives in
`docs/sample_data/` instead; a set here is scratch for one round of
checks.
