Observers view collated results without reviewing anyone (e.g., a tutor overseeing the tutorial groups). This page is optional; a session works without any observers at all. Observers have one tag slot rather than three, and never appear in assignments.

Each observer's cohort match rule decides which reviewees they may see, and an observer with no rule set sees nothing. Their results page stays empty until a rule is saved. What they see of each response (full, Anonymized, or Summarized) is set per instrument, not here.
