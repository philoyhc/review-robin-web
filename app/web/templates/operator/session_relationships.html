A relationship attaches context to one reviewer–reviewee pair, such as a shared group or a supervision link. Note that a session works without any explicitly set relationships at all. Set relationships to provide information that isn't already derivable from reviewer and reviewee tags.

Assignment rules are able to filter on the three tag columns, but only if they are populated. So put the pairwise context attributes meant to affect who reviews (or does not review) whom there (e.g., mentor–mentee, declared couple, conflict of interest).

Uploading a CSV replaces the whole relationship roster and clears any assignments already generated. To take specific relationships out of consideration for a running session without losing those rows, mark them inactive instead of deleting. You can also add new relationships on this page.

See Create and set up a session in the Guide.
