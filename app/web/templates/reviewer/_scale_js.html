{# A scale answer for a numeric response field (segment 20P Item 1): progressive enhancement of the number box. Each ``input[data-rs-scale]`` (with ``min``, ``max`` and ``data-rs-step``) gains a line with a circle. Up to 11 points it snaps, with a numbered stop at each point, and the box hides. Past 11 it slides, numbering Min, the midpoint and Max, and the box stays beside it for an exact value. The box keeps its name and value, so what is submitted, saved and checked does not change. Without script the box is all there is. Optional labels: ``data-rs-scale-start``, ``-middle``, ``-end``. Each scale states the narrowest it reads at (``minWidth``), set on the widget as a style and as ``data-rs-scale-min`` (px) for a column resizer to respect: a snap needs room for every numbered stop, a label row needs room for its words, a slide needs its three numbers. #}
