Run the probe

One HTTPS request from this server to Telegram's getMe, with a deliberately invalid bot token: no real token and no data about anyone is sent. Telegram refusing that token with its own error reply is the pass: it shows the request got through to Telegram.

Nothing is kept. The server log records the outcome, elapsed time and correlation ID only. Runs are at least {{ interval }} s apart.

What a pass does and doesn't show

  • It shows this server could reach Telegram's API when you ran it. Network policy can change later.
  • It doesn't test a real bot token, sending a message, or anything reaching a phone.
  • If it fails, give IT the time, the outcome and the correlation ID, never a screenshot of anything else.
