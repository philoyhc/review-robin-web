# cordware/docs/

**Reference material for the Cordware platform**, the host that mounts
Review Robin and the other applications. The host's contracts are in
`cordware/spec/`; RRW's own reference material is `docs/`.

| File | Covers |
|---|---|
| `cordware_mobile_to_desktop.md` | Mobile-to-desktop UX guidance for every Cordware application: responsiveness everywhere, mobile optimization per workflow, and the three UX classes each surface is given (moved 2026-10-25 from the private deployment repository; to `cordware/docs/` 2026-11-04). |
| `cordware_interoperability_consolidated_spec_v0.3.md` | **Proposed, 2026-11-04; not built.** Interoperability and application orchestration across Cordware applications: the capability contract, setup / status / result handoffs, the ApplyDesk ↔ Review Robin linked workflow, security boundaries and provenance. Not an authorization to implement or deploy. |
| `cordware_interoperability_agent_handoff_v0.3.md` | **Proposed, 2026-11-04.** The execution brief for the consolidated spec: reading order, repository pointers, phased increments, acceptance and reporting. Plans and approves slices; authorizes none. |
